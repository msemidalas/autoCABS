
This Python implementation provides an automated approach to generate auxiliary-complementary basis sets (autoCABS) from orbital basis sets for use in explicitly correlated F12 calculations.

For a double-zeta orbital basis (cardinal number is D), the script creates an autoCABS by generating geometrically averaged exponents, diffuse and tight functions plus two tight p exponents for the p-block elements, and two additional layers of exponents (AutoCABS2+-). For larger orbital basis sets, n = T, Q, 5, the program incorporates the geometrically averaged exponents, the diffuse functions, tight functions without additional p exponents, and only a single layer of exponents (AutoCABS1+-).

To use the program, follow these steps:

- Prepare a basis set file in ORCA or MOLPRO format for each element, naming them as 'Element.orca' or 'Element.mpro', respectively (e.g., 'c.orca' or 'c.mpro' for carbon).

- Place three files in a single folder: the autoCABS generation script, 'my_functions.py' with the function definitions, and the orbital basis set file (in either ORCA or MOLPRO format).

- To generate an autoCABS for n = D, execute the following command:

```python3 AutoCABS2+-.py```

To generate an autoCABS from a larger orbital basis set with a cardinal number n larger than D, use

```python3 AutoCABS1+-.py```

The autoCABS is exported in four different formats, MOLPRO, ORCA, TURBOMOLE, and Psi4.

To generate autoCABS for multiple elements, repeat the above steps for each element. A simple bash script is provided to assist in combining the generated autoCABS files into a single file.

Note added on November 26, 2023:
For generally contracted orbital basis sets with all contraction coefficients equal to 1, e.g., ANO-RCC-VnZP, the autoCABS is generated by using all orbital exponents per subshell, resulting to larger, automatically generated basis sets. 
This functionality has not been thoroughly tested for energetics and harmonic frequencies.
